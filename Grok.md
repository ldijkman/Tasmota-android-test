**This is a free, open-source Android app for controlling Tasmota Wi-Fi switches** (smart plugs/sockets running the popular Tasmota firmware).

### Key points
- **Fully local** — no cloud, no account, no MQTT, no Home Assistant required. Works only on your own Wi-Fi network.
- **No ads, no tracking, no data collection**. Location is only sent to *your own* Tasmota devices (for sunrise/sunset).
- Extremely lightweight (~60 KB install size).
- Android 7.0+.
- Source code is fully available in the repo (mainly in `plafond-led-app.zip`).

### Main features
- Fast network scan (finds Tasmota devices in ~2 seconds)
- On / Off / Toggle control with live status
- Up to 8 on/off timer pairs stored **directly on the Tasmota device** (so they keep working even when the phone is off)
- Sunrise / sunset support with offsets
- Friendly name & device name editing
- Device grouping, drag-and-drop sorting, custom icons for a tiles view
- Wi-Fi network switcher button + home-screen widget
- Direct link to the device’s built-in Tasmota web interface
