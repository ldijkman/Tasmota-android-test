Je Tasmota- en Shelly-schakelaars, één tik verwijderd.

Een gratis Android-app die elke Tasmota- en Shelly-schakelaar, -stekker en -lamp op je wifi in seconden vindt. Schakel ze, groepeer ze, en geef ze timers die meegaan met zonsopkomst en zonsondergang.

Geen cloud, geen account, geen reclame, geen limiet op apparaten. Gratis en open source.
Werkt met Tasmota en Shelly; OpenBeken deels.

Waar gaat dit over?

  1. Slimme stekkers en schakelaarsSommige lampen en stekkers hebben een piepklein computertje met wifi erin. Veel daarvan draaien het gratis programma Tasmota, andere zijn Shellys met hun eigen software. Deze app werkt met allebei.OpenBeken-apparaten werken ook deels.
  2. Ze praten via je wifiNet als je telefoon zijn ze verbonden met de wifi in je huis.
  3. Deze app is de afstandsbedieningHij vindt ze zelf. Tik op een plaatje en de lamp gaat aan. Tik nog eens en hij gaat uit.
  4. De schakelaar onthoudt hetZeg hem "aan als het donker wordt, uit om 11 uur". Dat blijft hij doen, ook als je telefoon uit staat.
  5. Alles blijft thuisGeen bedrijf ertussen, geen account, niets via internet. Geen dode apparaten als een bedrijf de ondersteuning stopt of failliet gaat: je schakelaars blijven werken.

Hoe de schema’s Comfort en Eco schakelen

Elk schema is een Shelly Schedule-taak, opgeslagen in de Shelly zelf. Op de aan-tijd voert hij KVS.Set th_level = "comfort" uit, op de uit-tijd KVS.Set th_level = "eco".

Het thermostaatscript leest th_level uit de KVS vóór elke controle (elke 30 s, en bij elke nieuwe temperatuur van de sensor), gebruikt th_comfort of th_eco als doel en schakelt het relais met een marge van 0,3 °C. De knoppen Comfort / Eco in de app schrijven dezelfde th_level met de hand, tot de volgende taak hem overschrijft.

De taken, de KVS en het script staan allemaal op de Shelly: geen telefoon, app, cloud of internet nodig. De telefoon is alleen om instellingen te wijzigen.

Voorbeeld: de thermostaat als script in de Shelly
Getest op een Shelly 1 Gen3. Nu ingebouwd in de app: Bewerken → Use as thermostat installeert hem voor je.

❄️ Geen vorstbeveiliging in het script: een script kan stoppen. Gebruik voor vorstbeveiliging mechanische hardware: een bimetaal-vorstthermostaat parallel aan het Shelly-relais, plus de eigen vorstbeveiliging van de ketel. 🔥 Tegen oververhitting: een normaal gesloten (NC) maximaalthermostaat, bijvoorbeeld 30 °C, in serie met het relais.

💡 Draait in de Shelly zelf: er hoeft geen browser, app of computer open te blijven. De Shelly voert de JavaScript zelf uit, ook zonder internet, en start hem na een stroomstoring weer op.

⏱️ Watchdog in de app: op de apparaatkaart zie je een uit-timer die aftelt vanaf 10 minuten en elke 30 seconden opnieuw begint. Dat is normaal: het script start hem steeds opnieuw. Stopt het script, dan loopt de timer af en zet de Shelly de verwarming zelf uit.

// Simple thermostat for a Shelly Gen2/Gen3 with the Sensor Add-on (DS18B20)
// EXAMPLE, A LITTLE BIT TESTED: try it with a lamp on the relay before you connect the boiler.
// NO FROST GUARD in this script: a script can stop. For frost protection use MECHANICAL HARDWARE:
// a bimetal frost thermostat wired in parallel with the Shelly relay (like the old Honeywell ones),
// plus the boiler's own frost protection. Those also work without power, Wi-Fi or software.
// For safety against overheating: a normally closed (NC) max thermostat (e.g. 30 °C) in series with the relay.
// Start with TEST_MODE = true and read the log; set it to false to really switch.
//
// Paste on the Shelly's own web page: Scripts -> Create script -> paste -> Save -> Start.
// Turn on "Run on startup" so it starts again after a power cut.
// It reacts at once when the temperature changes, and checks every 30 s as a backup.
// Watch what it does in the log under the script (lots of console.log lines),
// or open the log page in Chrome to copy it: http://<shelly-ip>/script/<script-number>/log
// (the exact address is in the first log line).
// The app "Shelly & Tasmota Scan & Control" can install this script and change the settings
// through KVS: th_comfort, th_eco (temperatures), th_level (comfort/eco), th_mode (on/off),
// th_sensor (number), th_test (on/off). The app's schedules set th_level at the switch times.

// ================= SETTINGS: change these =================

let TEST_MODE        = true;    // true  = only write in the log, never switch the relay (app: KVS "th_test")
                                // false = really switch the relay (heating)

let COMFORT          = 20.5;    // Comfort temperature (°C), app: KVS "th_comfort"
let ECO              = 16.0;    // Eco temperature (°C), app: KVS "th_eco"
let LEVEL            = "comfort";  // "comfort" or "eco": set by the schedules in the Shelly, app: KVS "th_level"
let SWITCH_MARGIN    = 0.3;     // heat below 19.7, stop above 20.3

let SENSOR           = 100;     // Add-on sensor number (see the Shelly page: Temperature (100)), app: KVS "th_sensor"

let CHECK_EVERY_SECONDS = 30;   // how often to look at the temperature
let MIN_MINUTES_BETWEEN = 0;    // 0 = react directly; some boilers want e.g. 3 minutes between switching
let SAFETY_OFF_MINUTES  = 10;   // relay turns off by itself if the script stops

// ================= do not change below this line =================

let VERSION = 4;                // the app checks this to offer an update of the script

let CFG = {
  dryRun: TEST_MODE,
  sensor: SENSOR,
  comfort: COMFORT,
  eco: ECO,
  level: LEVEL,
  setpoint: COMFORT,
  hyst: SWITCH_MARGIN,
  minSwitchSec: MIN_MINUTES_BETWEEN * 60,
  everySec: CHECK_EVERY_SECONDS,
  watchdogSec: SAFETY_OFF_MINUTES * 60
};

let state = { heating: false, lastSwitch: 0, mode: "on", round: 0 };  // mode: "on" or "off" (KVS "th_mode")

// clock time for the log: "04:43:12" (local time of the Shelly),
// or the seconds since start ("29332s") as long as the Shelly does not know the time yet
function clock() {
  let sys = Shelly.getComponentStatus("sys");
  if (sys && sys.time && sys.unixtime) {
    let sec = sys.unixtime % 60;
    return sys.time + ":" + (sec < 10 ? "0" : "") + sec;
  }
  return (sys ? sys.uptime : 0) + "s";
}

// keep the last log lines in memory for the log page (small: the Shelly has little memory)
let LOG = [];
let LOG_MAX = 60;
// one decimal, rounded the same way everywhere (26.55 -> "26.6")
function f1(x) {
  return (Math.round(x * 10) / 10).toFixed(1);
}

function log(msg) {
  console.log("[thermostat] " + msg);
  LOG.push(clock() + " " + msg);
  if (LOG.length > LOG_MAX) LOG.splice(0, LOG.length - LOG_MAX);
}

// log page: http://<shelly-ip>/script/<script-number>/log  (plain text, easy to copy)
HTTPServer.registerEndpoint("log", function (req, res) {
  res.code = 200;
  res.headers = [["Content-Type", "text/plain; charset=utf-8"]];
  res.body = "Thermostat log (last " + LOG.length + " lines, newest at the bottom)\n\n" + LOG.join("\n") + "\n";
  res.send();
});

// read the settings the app could write in KVS (the Shelly's own storage); done() runs when all are read
function kvs(key, use, done) {
  Shelly.call("KVS.Get", { key: key }, function (r, err) {
    if (!err && r && r.value !== undefined) use(String(r.value));
    done();
  });
}
function temp(v) { let n = Number(v); return n >= 5 && n <= 30 ? n : null; }
function useLevel() {   // the temperature the thermostat heats to: Comfort or Eco
  let t = CFG.level === "eco" ? CFG.eco : CFG.comfort;
  if (t !== CFG.setpoint) log("now " + CFG.level + ": " + f1(t) + " °C");
  CFG.setpoint = t;
}
// all settings in ONE call: a Shelly allows only a few calls at the same time
function loadSettings(then) {
  Shelly.call("KVS.GetMany", { match: "th_*" }, function (r, err) {
    let kv = {};
    if (!err && r && r.items) {
      if (r.items.length !== undefined) {           // newer firmware: a list
        for (let i = 0; i < r.items.length; i++) kv[r.items[i].key] = String(r.items[i].value);
      } else {                                      // older firmware: an object
        for (let k in r.items) kv[k] = String(r.items[k].value);
      }
    } else if (err) log("could not read the settings (error " + err + "), keep the old ones");
    if (kv.th_comfort !== undefined) {
      let n = temp(kv.th_comfort);
      if (n === null) log("KVS th_comfort = " + kv.th_comfort + " is out of range (5-30), ignored");
      else { if (n !== CFG.comfort) log("Comfort changed: " + f1(CFG.comfort) + " -> " + f1(n) + " °C"); CFG.comfort = n; }
    }
    if (kv.th_eco !== undefined) {
      let n = temp(kv.th_eco);
      if (n === null) log("KVS th_eco = " + kv.th_eco + " is out of range (5-30), ignored");
      else { if (n !== CFG.eco) log("Eco changed: " + f1(CFG.eco) + " -> " + f1(n) + " °C"); CFG.eco = n; }
    }
    let v = kv.th_level;
    if (v === "comfort" || v === "eco") { if (v !== CFG.level) log("level changed: " + CFG.level + " -> " + v); CFG.level = v; }
    v = kv.th_mode;
    if (v === "on" || v === "off") { if (v !== state.mode) log("mode changed: " + state.mode + " -> " + v); state.mode = v; }
    if (kv.th_sensor !== undefined) {
      let n = Number(kv.th_sensor);
      if (n >= 100 && n <= 199) { if (n !== CFG.sensor) log("sensor changed: " + CFG.sensor + " -> " + n); CFG.sensor = n; }
    }
    v = kv.th_test;
    if (v === "on" || v === "off") {
      let test = v === "on";
      if (test !== CFG.dryRun) log("TEST MODE changed: " + (test ? "on (relay is never switched)" : "OFF (relay really switches!)"));
      CFG.dryRun = test;
    }
    useLevel();
    if (then) then();
  });
}

// the schedules write th_level; read it at every check (reading KVS does not wear the flash)
function loadLevel(then) {
  kvs("th_level", function (v) { if ((v === "comfort" || v === "eco") && v !== CFG.level) { log("schedule: level " + CFG.level + " -> " + v); CFG.level = v; } },
    function () { useLevel(); then(); });
}

// state page for the app: http://<shelly-ip>/script/<script-number>/state  (JSON)
let lastTemp = null, lastCheck = 0;
HTTPServer.registerEndpoint("state", function (req, res) {
  res.code = 200;
  res.headers = [["Content-Type", "application/json"]];
  res.body = JSON.stringify({ thermostat: 1, temp: lastTemp, set: CFG.setpoint, comfort: CFG.comfort, eco: CFG.eco,
    level: CFG.level, margin: CFG.hyst, mode: state.mode,
    heating: state.heating, test: CFG.dryRun, sensor: CFG.sensor, round: state.round, checked: lastCheck,
    watchdog: CFG.watchdogSec, version: VERSION });
  res.send();
});

// the app calls this right after changing a setting, so it works at once instead of within 5 minutes
HTTPServer.registerEndpoint("reload", function (req, res) {
  log("settings reload asked (by the app)");
  loadSettings(check);
  res.code = 200;
  res.headers = [["Content-Type", "application/json"]];
  res.body = JSON.stringify({ ok: true });
  res.send();
});

// room temperature from the sensor, or null if it gives no value
function roomTemp() {
  let st = Shelly.getComponentStatus("temperature", CFG.sensor);
  if (st && typeof st.tC === "number") {
    log("sensor " + CFG.sensor + ": " + f1(st.tC) + " °C");
    return st.tC;
  }
  log("sensor " + CFG.sensor + ": NO VALUE (not connected, wrong number or broken?)");
  return null;
}

function setHeating(on, why) {
  if (on === state.heating) {
    log("heating stays " + (on ? "ON" : "OFF") + " (" + why + ")");
    return;
  }
  let now = Shelly.getComponentStatus("sys").uptime;
  let since = now - state.lastSwitch;
  // switching off for safety or because you turned the thermostat off is always allowed; otherwise wait
  if (why !== "safety" && why !== "mode off" && state.lastSwitch > 0 && since < CFG.minSwitchSec) {
    log("want heating " + (on ? "ON" : "OFF") + " but last switch was " + since + " s ago, wait until " + CFG.minSwitchSec + " s");
    return;
  }
  if (CFG.dryRun) {
    log("TEST MODE: would turn heating " + (on ? "ON" : "OFF") + " (" + why + "), relay NOT switched");
  } else {
    log("switching heating " + (on ? "ON" : "OFF") + " (" + why + ")" + (on ? ", watchdog " + CFG.watchdogSec + " s" : ""));
    let args = on ? { id: 0, on: true, toggle_after: CFG.watchdogSec } : { id: 0, on: false };
    Shelly.call("Switch.Set", args, function (r, err, msg) {
      if (err) log("ERROR switching relay: " + err + " " + msg);
      else log("relay switched " + (on ? "ON" : "OFF") + ", was " + (r && r.was_on ? "ON" : "OFF"));
    });
  }
  state.heating = on;
  if (!CFG.dryRun) state.lastSwitch = now;   // test mode: no real switch, so no boiler wait afterwards
}

// watchdog: while heating, set "on, and off again after watchdogSec" every check.
// Each refresh starts the timer over; if the script stops, the Shelly switches off by itself.
function refreshWatchdog() {
  if (!state.heating) return;
  if (CFG.dryRun) { log("TEST MODE: would refresh watchdog (" + CFG.watchdogSec + " s)"); return; }
  Shelly.call("Switch.Set", { id: 0, on: true, toggle_after: CFG.watchdogSec }, function (r, err, msg) {
    if (err) log("ERROR refreshing watchdog: " + err + " " + msg);
    else log("watchdog refreshed: relay turns off by itself in " + CFG.watchdogSec + " s if the script stops");
  });
}

let busy = false;   // one check at a time (a Shelly allows only a few calls at once)
function check() {
  if (busy) return;
  busy = true;
  loadLevel(function () { busy = false; doCheck(); });
}
function doCheck() {
  state.round++;
  // compare with the real relay: it may have been switched by hand, by the watchdog or a schedule
  if (!CFG.dryRun) {
    let sw = Shelly.getComponentStatus("switch", 0);
    let real = !!(sw && sw.output);
    if (real !== state.heating) {
      log("relay is " + (real ? "ON" : "OFF") + " but script thought " + (state.heating ? "ON" : "OFF") + " (switched by hand, watchdog or schedule?)");
      state.heating = real;
    }
  }
  log("---- check " + state.round + " · " + CFG.level + " " + f1(CFG.setpoint) + " °C · mode " + state.mode +
      " · heating " + (state.heating ? "ON" : "OFF") + (CFG.dryRun ? " · TEST MODE" : "") + " ----");
  let t = roomTemp();
  lastTemp = t === null ? null : Math.round(t * 10) / 10;
  let sys = Shelly.getComponentStatus("sys");
  lastCheck = sys && sys.unixtime ? sys.unixtime : 0;
  if (t === null) {                       // no sensor works: heating off
    log("no temperature: heating off for safety");
    setHeating(false, "safety");
    return;
  }
  if (state.mode === "off") {
    setHeating(false, "mode off");
    return;
  }
  let low = CFG.setpoint - CFG.hyst, high = CFG.setpoint + CFG.hyst;
  log("heat below " + f1(low) + " °C, stop above " + f1(high) + " °C");
  if (t < low) setHeating(true, f1(t) + " < " + f1(low));
  else if (t > high) setHeating(false, f1(t) + " > " + f1(high));
  else log(f1(t) + " °C is between " + f1(low) + " and " + f1(high) + ": no change (heating stays " + (state.heating ? "ON" : "OFF") + ")");
  refreshWatchdog();
}

// start: read the relay as it is now, then check every 30 s (settings every 5 min)
let wifi = Shelly.getComponentStatus("wifi");
log("log page: http://" + (wifi && wifi.sta_ip ? wifi.sta_ip : "<shelly-ip>") + "/script/" + Shelly.getCurrentScriptId() + "/log");
let sw = Shelly.getComponentStatus("switch", 0);
state.heating = !!(sw && sw.output);
log("script started · TEST MODE " + (TEST_MODE ? "on (relay is never switched)" : "OFF (relay really switches!)") +
    " · Comfort " + f1(COMFORT) + " °C · Eco " + f1(ECO) + " °C · margin " + SWITCH_MARGIN + " · no frost guard (use a mechanical one)");
log("sensor " + SENSOR + " (KVS th_sensor can change it) · check every " + CHECK_EVERY_SECONDS + " s · wait " + MIN_MINUTES_BETWEEN +
    " min between switching · safety off after " + SAFETY_OFF_MINUTES + " min · relay is now " + (state.heating ? "ON" : "OFF"));
// react at once when the sensor reports a new temperature (every change of its threshold, e.g. 0.1 °C);
// the check every 30 s stays as a backup
let soon = null;
Shelly.addStatusHandler(function (e) {
  if (!e || e.component !== "temperature:" + CFG.sensor || !e.delta || e.delta.tC === undefined) return;
  if (soon !== null) return;                        // several reports at once: one check
  soon = Timer.set(300, false, function () { soon = null; log("new temperature from the sensor"); check(); });
});

loadSettings(function () {   // first the settings from KVS, then the first check
  Timer.set(CFG.everySec * 1000, true, check);
  Timer.set(300 * 1000, true, function () { loadSettings(); });
  check();
});

Vragen die mensen stellen.

Iets anders? Vraag het op GitHub.

Welke apparaten werken?

Elk apparaat met Tasmota-firmware: Sonoff, Athom en andere stekkers, relais, wandschakelaars, lampen en ledstrips met een ESP8266- of ESP32-chip.

Shelly-apparaten met hun eigen firmware: Gen2 en nieuwer (Plus, Pro, Mini, Gen3, Gen4) met schakelen, lampen, schema’s en automatisch uit; Gen1 deels.

Apparaten met andere firmware, zoals eWeLink of Tuya, hebben eerst Tasmota nodig.

Gaat mijn lamp via een server in China?

Nee, je lamp blijft thuis. Als je op een schakelaar tikt, gaat het signaal een paar meter over je eigen wifi, direct van je telefoon naar de schakelaar. Veel slimme-huis-apps sturen het eerst naar een cloudserver, soms aan de andere kant van de wereld, en dan weer terug, alleen om de lamp naast je aan te zetten. Met deze app is de reis naar de lamp korter dan de reis naar de koelkast.

Op welke telefoons werkt het?

Android 7 of nieuwer. Een nieuw apparaat toevoegen vanuit de app vraagt Android 10 of nieuwer. Er is geen iPhone-versie, maar je kunt de live demo in elke browser proberen.

Waarom staat hij niet in de Play Store?

Ik maak deze app alleen, in mijn vrije tijd. Een nieuwe app in de Play Store krijgen betekent: betalen, een identiteitscontrole, en eerst 12 testers vinden die hem 14 dagen geïnstalleerd houden. Dat is veel gedoe voor een gratis hobby-app. Daarom download je hem direct van GitHub.

Android waarschuwt bij het installeren. Is het veilig?

De app staat niet in de Play Store, dus Google Play Protect kent hem nog niet. Je kunt Play Protect hem eerst laten scannen, of installeren zonder scan. De volledige broncode staat openbaar op GitHub, en GitHub bouwt de download zelf van die broncode. Sinds 21 november 2026 ben ik een bij Google geregistreerde ontwikkelaar, en de app is geregistreerd bij Googles Android-ontwikkelaarsverificatie. Op de meeste telefoons vraagt Android niet meer om hem te scannen.

Bekijk de installatievideo (1,5 min)

Werkt het met OpenBeken of Shelly?

OpenBeken-apparaten werken deels: schakelen wel, schema’s niet. Shelly-apparaten werken volledig als ze Tasmota-firmware hebben.

Nieuw en nog niet getest: de app kan nu ook Shelly-apparaten met hun eigen firmware vinden, aan- en uitzetten, helderheid, wit en kleur instellen op Shelly-lampen, ze hernoemen en hun automatisch uit instellen, en een nieuwe Shelly aan je wifi toevoegen (Gen1 tot Gen4). Getest op een echte Shelly 1 Gen3. Schema’s werken ook op Gen2 en nieuwer (dezelfde schemakaarten, met zonsopkomst en zonsondergang), opgeslagen in de Shelly zelf. Stroomverbruik voor Shelly zit er nog niet in.

Waarom niet de Shelly-app?

Je hoeft niet te kiezen. Beide apps kunnen op je telefoon staan en dezelfde Shelly bedienen.

De Shelly-app wordt gemaakt door Shelly zelf. Hij werkt met elke Shelly, en alleen met Shelly. Ook buiten de deur, en met Alexa of Google Home. Je hebt er een Shelly-account voor nodig.

Deze app is kleiner en simpeler. Geen account. Alles blijft thuis. Je Tasmota- en Shelly-schakelaars staan op één scherm.

Ze werken naast elkaar. Zet de lamp aan in de ene app, en de andere app laat hem ook aan zien. Automatisch uit en schema’s staan in de Shelly zelf, dus ze blijven werken, welke app je ook gebruikte.

Let op: deze app maakt schema’s als aan/uit-paren: één aan-tijd en één uit-tijd per schema. Schema’s die je in de Shelly-app maakt, verschijnen misschien niet in deze app, maar ze blijven werken in de Shelly.

Een goede mix: de Shelly-app om een nieuwe Shelly in te stellen, deze app voor elke dag.

Waarom vraagt hij om mijn locatie?

Voor de tijden van zonsopkomst en zonsondergang, die de app naar je schakelaars stuurt. Android vraagt ook locatietoestemming voordat een app wifinamen in de buurt mag zien. Je locatie gaat alleen naar je eigen schakelaars.

Wat is een VPN?

Een VPN (virtueel privénetwerk) is een privé, versleutelde verbinding tussen je eigen apparaten via internet. Met Tailscale VPN maakt je telefoon buiten de deur verbinding met een oude telefoon of tablet thuis, alsof je op je eigen wifi zit. Alleen je eigen apparaten kunnen het gebruiken, en je hoeft geen poorten open te zetten in je router. Tailscale is gratis voor persoonlijk gebruik.

Hoe krijg ik updates?

Scrol naar beneden op het hoofdscherm en tik op Check for update. De app downloadt de nieuwste versie van GitHub en installeert hem.

Hoeveel schakelaars kan ik toevoegen?

Zoveel als je wilt. Er is geen limiet op schakelaars, groepen, scènes of widgets, en geen betaalde versie die meer vrijgeeft. Alleen Tasmota zelf heeft een limiet: tot 8 aan/uit-schema’s per schakelaar.

Wat kost het?

Niets. Geen reclame, geen aankopen in de app, geen abonnement.

De ESP8266 kwam uit in 2014,

Leuk weetje:
De ESP8266 begon als een wifimodem van 2 dollar,
bestuurd met AT-commando’s
uit het tijdperk van de telefoonmodems uit de jaren 80.
In het begin was de documentatie moeilijk te vinden,
en alleen in het Chinees.
Hobbyisten ontdekten dat hij eigen programma’s kon draaien,
en daaruit groeiden Tasmota en Shelly.

Meer: van modem tot kleine computer
  • 2014: het ESP-01-bordje werd eerst gebruikt als goedkope wifi-uitbreiding voor een Arduino. De Arduino stuurde het AT-commando’s, net als een modem.
  • Eind 2014: Espressif bracht een officiële SDK uit, en NodeMCU verscheen, waarmee je de ESP8266 zelf kon programmeren in de taal Lua. Dat was de eerste grote stap van “modem” naar “kleine computer”.
  • 2015: Ivan Grokhotkov maakte de ESP8266 Arduino-core. Vanaf toen kon je de ESP8266 direct vanuit de Arduino IDE programmeren, helemaal zonder Arduino-bordje. Daardoor werd hij razend populair.
  • Tasmota is gebouwd op die ESP8266 Arduino-core, dus het groeide uit de Arduino-wereld.
