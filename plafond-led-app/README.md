# Tasmota Scan & Control – Android app

Free Android app to find, switch and schedule Tasmota Wi-Fi switches, plugs and lamps
on your own network. No cloud, no account, no ads. Shelly devices partly work too.

- Website: https://ldijkman.github.io/Tasmota-android-test/
- Source and releases: https://github.com/ldijkman/Tasmota-android-test

## Build
GitHub Actions builds the APK from this folder (`plafond-led-app.zip` in the repository).
The user interface is in `app/src/main/assets/index.html`, the Android part in
`app/src/main/java/nl/dijkman/plafondled/`.
